# Side Hustle Income Tracker

A local-first income and payout tracker for YouTube, TikTok Affiliate, Shopee Affiliate, and other creator income streams.

## Planned features

- Earnings reports with custom reporting-period start and end dates
- Separate payout history so earnings and cash received are not double-counted
- Monthly and annual dashboards, charts, and platform breakdowns
- PHP currency and configurable monthly income target
- Local-first storage with import/export backups
